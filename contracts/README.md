# ⛓️ AgentPay Smart Contracts

This directory contains the Solidity smart contracts and EVM deployment/testing scripts for AgentPay.

## Overview
- `AgentPay.sol`: Main settlement and policy-enforced payment escrow contract.
- `MockUSDC.sol`: Standard ERC-20 token for testnet micro-transactions.
- `PaymentManager.sol`: Multi-agent spending limit manager and whitelist registry.
